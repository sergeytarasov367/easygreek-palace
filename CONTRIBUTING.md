# Как участвовать

Спасибо, что хотите помочь! Перед первым вкладом прочитайте условия.

## Условия

1. **Лицензия вклада.** Отправляя pull request, вы соглашаетесь, что ваш вклад публикуется под лицензией MIT. Его может использовать кто угодно, в том числе EasyGreek — в своём коммерческом продукте.
2. **Без оплаты.** Участие добровольное: денег, сроков и обязательств ни с одной стороны нет. Это не трудовой договор и не стажировка.
3. **Возраст.** Участвовать можно с 18 лет. Если вам меньше 18 — только с согласия родителя или опекуна: напишите об этом в описании первого pull request.
4. **Чужие материалы.** Модели, картинки и звуки — только с открытой лицензией (CC0, например [Kenney](https://kenney.nl)), с файлом лицензии рядом. Ничего, скачанного без прав.

## Как прислать изменение

1. Сделайте fork и ветку от `main`.
2. Проверьте игру локально (`python3 -m http.server 8000`) на компьютере и, если можете, на телефоне.
3. Откройте pull request в `main`: что сделано и как проверить. Лучше несколько небольших, чем один огромный.

## Греческий

Только формы уровня A2. Каждую новую фразу мы проверяем перед слиянием, поэтому в описании pull request перечислите новые греческие слова и фразы с переводом. Озвучку можно сделать через `tools/say.py`; на сайте мы озвучим сами.

## Идеи

Новые места (магазин, остановка, кафе, аптека, рынок), задания персонажей, диалоги для экзамена, удобство управления на телефоне.
